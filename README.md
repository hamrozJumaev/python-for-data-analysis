# Python for Data Analysis — Working Through McKinney

My notes, code, and exercises from working through **"Python for Data Analysis" (3rd ed.)** by Wes McKinney, the creator of pandas.

This repo is part of my path toward becoming a data scientist. I'm publishing my progress in the open both to hold myself accountable and to leave a trail of how I learned.

## Why this book

McKinney built pandas, so this is as close to the source as it gets for learning data manipulation in Python. I'm focusing on:

- Fluency with pandas (not just familiarity)
- Understanding *why* operations work the way they do, not just memorizing syntax
- Building muscle memory for the daily tools of a data scientist

## How I'm working through it

- **One chapter every 1-2 weeks**, alongside other learning (SQL, statistics)
- Type every code example by hand — no copy-paste
- After each chapter, write a short notes file summarizing what I learned in my own words
- Solve at least 2-3 extra problems per chapter using a different dataset
